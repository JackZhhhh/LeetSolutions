## 📂 Repository Structure

Each problem has its **own folder**, generated automatically by **LeetSync**.

Inside each folder you will typically find:
- The **problem description**
- My **C++ solution file**

Example structure:
├── 0001-two-sum/
│ ├── README.md // Problem description
│ └── solution.cpp // My C++ solution
│
├── 0020-valid-parentheses/
│ ├── README.md
│ └── solution.cpp

This structure makes it easy to review problems individually and understand the context behind each solution.
